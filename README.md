# Gireesh V. Pai — Developer Portfolio

A lightweight, responsive developer portfolio built with plain HTML, CSS and a tiny JavaScript snippet. No framework, package manager, build step or backend is required.

## Deploy with GitHub Pages

1. Create a **public** repository named `gireeshvpai2007-maker.github.io`.
2. Upload `index.html` to the repository root (not inside a subfolder).
3. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Wait for the deployment to finish. The site should appear at `https://gireeshvpai2007-maker.github.io/`.

## Before publishing

- Add the exact public GitHub URL for NetForge when ready.
- If you want an email contact, add your preferred public email; this version intentionally only links to GitHub.
- Keep the project descriptions accurate as your work evolves.

## Local preview

Double-click `index.html` to open it in a browser. No installation is required.
